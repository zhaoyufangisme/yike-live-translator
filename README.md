# 译刻

一款简洁的实时翻译与汇率换算应用，支持外语与中文双向翻译、语音输入、文字朗读、图片 OCR，以及外币与人民币换算。

## 在线使用

[打开译刻](https://yike-live-translator-2026.wwpbbms123.chatgpt.site/)

## 下载安装包

进入仓库右侧的 **Releases**，下载最新版：

- Windows：`Yike-Setup-*.exe`
- Android：`Yike-Android.apk`

安装包是联网应用，需要网络连接。首次使用可能需要完成应用访问登录。Android 安装 APK 时，系统可能要求允许“安装未知应用”。

## 功能

- 14 种主流外语与中文实时互译
- 图片文字提取与版式保留
- 语音识别和文字朗读
- 实时汇率与双向金额换算
- 记住上次选择的国家或货币
- PWA、Windows 和 Android 安装方式
